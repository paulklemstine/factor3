The node coordinates ARE the Fermat decomposition (m = c, n = b; p = m−n, q = m+n). Both trees therefore enumerate *all* Fermat decompositions of all odd numbers, each exactly once (3^L nodes at level L, verified to L = 11; parent maps verified to invert the child maps on 50,564 nodes, zero failures). Factoring N ⟺ finding the N-node. **(2) The interlock is algebraic inequivalence over a shared vertex set:** Berggren's child maps (2m−n,m), (2m+n,m), (m+2n,n) have 2×2 determinants {+1, −1, +1} (unimodular, a subtract-2/reflect Euclidean descent); Price's (m+n,2n), (2m,m−n), (2m,m+n) have determinants {+2, −2, +2} (a halving-the-even-coordinate descent — the structure of Stein's binary GCD). Determinants are conjugacy invariants, so no change of coordinates turns one tree into the other. The leg swap (a↔b) *is* an automorphism of the Berggren tree (S·B·S permutes {B₁,B₂,B₃}, 3/3) but **not** of the Price tree (S·P·S hits none of {P₁,P₂,P₃}, 0/3) — the interlock is asymmetric. ## 1. Setup

All primitive Pythagorean triples ⟺ coprime opposite-parity pairs (m,n), m > n, with odd leg a = m²−n², even leg b = 2mn, hypotenuse c = m²+n², seed (2,1) = (3,4,5). **Berggren child maps:** (2m−n,m), (2m+n,m), (m+2n,n) — each unimodular (2×2 det {+1,−1,+1}); parent: if M < 2N: (N, 2N−M), elif M < 3N: (N, M−2N), else (M−2N, N) — a "subtract-2N" Euclidean descent. **Price child maps:** (m+n,2n), (2m,m−n), (2m,m+n) — det {+2,−2,+2}; parent: if N even: (M−N/2, N/2), elif M > 2N: (M/2, M/2−N), else (M/2, N−M/2) — a "halve-the-even-coordinate" descent. 3×3 triple matrices: Berggren dets {1,−1,1}, Price dets {8,−8,8}. Fermat decomposition: N = pq = c²−b² with c = (p+q)/2, b = (q−p)/2. Metrics: BFS levels (3^L), parent-inversion failures, depth via parent-descent, Pearson correlations, tree-work 3^d vs Fermat steps d_F = c − isqrt(N).

## 2. Both trees enumerate the same vertices, exactly once (verified)

BFS to L = 11: |B_L| = |P_L| = 3^L for every L (265,720 nodes each, no duplicate triples within a tree). Parent maps verified: 0 Berggren and 0 Price failures on all 50,564 valid (m,n) with m ≤ 500 — every parent is itself valid and the child map inverts it. Both trees enumerate the same infinite set of primitive triples; the two different BFS truncations at depth 11 simply reach different c-thresholds.

## 3. The N-node identity: every semiprime is a node of both trees (new, exact)

For N = p·q (p < q odd primes): m = (p+q)/2, n = (q−p)/2 satisfies m > n ≥ 1, gcd(m,n) = 1 (any common divisor divides both p = m−n and q = m+n), and m+n = q odd ⟹ opposite parity. So (m,n) is a valid node of **both** trees. Its odd leg: m²−n² = (m−n)(m+n) = pq = N **exactly**; hypotenuse (p²+q²)/2, even leg (q²−p²)/2, and indeed N² + ((q²−p²)/2)² = ((p²+q²)/2)². Verified on 1020/1020 random 11–12-bit prime pairs; example 2003·2011 = 4,028,033 sits at node (2007, 4) with odd leg 4,028,033 = N, m−n = 2003 = p, m+n = 2011 = q.

**Consequence.** The two trees are complete, duplicate-free tables of *all* Fermat decompositions of *all* odd integers: the node whose odd leg is N exists exactly once in each tree, and its coordinates are precisely the Fermat pair (c, b) = ((p+q)/2, (q−p)/2). This refines the earlier hypotenuse-coordinate probe (which tested m²+n² = N — the wrong coordinate; the sum-of-two-squares question, relevant to Euler's method, not to Fermat's). The correct embedding is odd-leg = N, and it is exact for both trees.

## 4. The interlock: inequivalence over a shared vertex set (verified)

1. **No conjugacy.** |det| is a conjugacy invariant. The 2×2 (m,n) maps have dets {±1} (Berggren) vs {±2} (Price); the 3×3 triple matrices have dets {1,−1,1} vs {8,−8,8}. No change of basis can carry one child-map set to the other — the trees are genuinely inequivalent structures on the same vertex set.
2. **Leg-swap asymmetry.** With S = (a↔b), S·B·S permutes {B₁,B₂,B₃} (3/3 matched: B₁↔B₃, B₂ fixed — Berggren is leg-symmetric), but S·P·S hits *none* of {P₁,P₂,P₃} (0/3) — Price is an oriented structure built around the even leg. The interlock is asymmetric: one tree is leg-symmetric, the other is not.
3. **Descents almost never agree.** B-parent = P-parent on exactly 2 of 455,736 valid nodes — only (3,2) and (4,1), the two shared level-1 children. The two routes to the root coincide only where both are one step.
4. **Depth duality.** dB and dP are two different "distance from root" metrics on the same set: dB is the length of the subtract-2/reflect continued-fraction descent of m/n (ratio-sensitive), dP is the length of the halving/binary-GCD descent (size-sensitive). For the N-node of 20-bit primes: dB mean 78.5, range **[19, 1135]** (a 60× spread); dP mean 25.8, sd 2.4, range [19, 32]. Across bit-sizes the Price depth is tight and linear in the size: dP mean 17.7/21.4/25.8/30.1 at 14/17/20/23-bit primes (≈ 1.4·log₂(p+q)). corr(dB, dP) = −0.16: the two orderings of the same vertices are essentially independent. (Exact closed forms for the depth counts resisted standard CF sums — ≤ 35% hit rates — and are characterized structurally by the reflection steps of each descent.)

## 5. Factoring verdict: exact identification, zero leverage (verified)

1. **Tree traversal never wins.** Work to reach the N-node by tree search is 3^dB. Measured over 209 random 20-bit semiprimes: **0/209** times did 3^dB beat Fermat's own scan (Fermat mean 6,630 steps; the shallowest N-node had dB = 19, still 3^19 ≈ 1.2×10⁹ ≫ 6,630). Tree-BFS enumerates by depth (×3 per level); Fermat enumerates by c-value (linear). The tree order is exponentially worse.
2. **The path is the factorization.** The ternary string of child-choices on the root→N path encodes the binary/CF structure of (m,n) = the Fermat pair = (p,q). No N-only rule picks branches, and no pruning exists: the odd leg can stay almost constant along a branch (the staircase triples (k,k−1) → (k+1,k) via the det −1 child), so no "odd leg < N" cutoff ever prunes the N-node's subtree.
3. **The trees measure the opposite of Fermat hardness.** corr(dB, log₂ Fermat-steps) = **−0.31** — Berggren calls an N "deep" exactly when Fermat finds it fast (the tree depth is a function of the ratio (p+q)/(q−p), and Fermat cost ≈ (q−p)²/(8√N)); corr(dP, log₂ Fermat-steps) = +0.16 ≈ 0 — Price ranks every N of a given size at nearly the same depth, blind to the factor structure entirely.
4. **No leg-only descent.** Walking *up* from N while tracking only odd legs is not closed: for the Berggren child (2m−n, m), the child's odd leg 3m²−4mn+n² is not a function of the parent's odd leg m²−n² alone — the pair (m,n), i.e. the factorization, is required. (Hypotenuse-coordinate density m²+n² ≡ 0 mod N in both trees is ≤ the random 4/N, and exactly 0 for primitive pairs when N has a small prime factor — N = 15, 21, 35, 77, 91 give zero in both trees.)

## 6. Conclusion

BERGGREN-PRICE-INTERLOCK closes the Pythagorean-tree line with exact statements. The interlock is: two inequivalent Euclidean descents (subtract-2/reflect CF-descent vs halving/binary-GCD descent — no conjugacy by determinant, leg-swap asymmetry) over the same vertex set of primitive triples, which is also the complete table of Fermat decompositions. Every odd semiprime N is a node of both trees at its Fermat pair, exactly once, with odd leg N — but finding that node by traversal costs 3^d ≫ d_F, the path string is the factorization, and the depth metrics are either anti-correlated with Fermat hardness (Berggren) or size-blind (Price). The trees organize the *ratio* (p+q)/(q−p) — a coordinate measuring how close p and q are, i.e. Fermat's difficulty — while factoring needs the *product* pq; the ratio↔product map is the factorization step. This is barrier 5 (structural orthogonality) sharpened to exact, verified form, and barrier 8 (the tree is Fermat's method in a different order — "known method in disguise"). No usable factoring insight: the identification is exact and beautiful, and entirely circular.
